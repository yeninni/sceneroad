# SceneRoad 씬로드

K-콘텐츠 촬영지와 로컬 상권을 잇는 투어 앱 프로토타입입니다. 드라마 촬영지와 그 주변의 맛집, 카페, 전통찻집, 골목 상점을 한 화면에 모아 보여 주고, 방문객에게는 취향에 맞춘 도보 코스를, 소상공인에게는 방문 흐름과 운영 팁을 제공합니다.

## 이번 개편에서 더한 것

- **타이포그래피**: 제목과 숫자에 Plus Jakarta Sans, 픽셀 라벨에 Silkscreen, 한글 본문에 SUIT Variable을 조합했습니다.
- **픽셀 가이드 캐릭터**: 하늘색 버킷햇과 필름 카메라를 든 픽셀 여행자 `씬로`를 SVG로 직접 그려 홈 히어로, 도보 코스 말풍선, 좌우 패널에 배치했습니다.
- **외국인 개인화**: 언어 세 가지(EN, JP, KR)와 여행 취향 다섯 가지를 고르면 가이드 멘트, 추천 촬영지, 도보 코스, 스팟 카드가 함께 바뀝니다. 스팟 카드에는 영어 메뉴 여부, 도보 시간, 추천 이유가 붙고 영어 메뉴만 골라 보는 필터도 있습니다.

## 화면

| 번호 | 화면 | 내용 |
| --- | --- | --- |
| 01 | 방문객 홈 | 촬영지 히어로, 여행 취향 태그, 가이드 멘트, 맞춤 코스 카드, 취향별 추천 스팟 |
| 02 | 씬로드 파트너 | 보행 점수 88점, 외국인 소비 비중 34.2%, 시간대별 방문 흐름, 운영 팁, 가이드가 짠 오늘의 코스 |
| 03 | 도보 코스 | 미니 동선 지도, 가이드 안내, 카테고리 필터, 취향별 3개 스텝과 도보 시간, 영어 메뉴 표시 |
| 04 | 로컬 스팟 | 다섯 곳 상세 카드, 추천 이유, 도보 시간, 영어 메뉴 여부와 필터 |

## 보는 방법

- **전체 한눈에 보기**: 네 개의 폰 목업과 좌우 요약을 한 화면에 놓은 기획서용 화면입니다. 폰을 누르면 크게 열립니다.
- **모바일로 체험하기**: 폰 한 대를 크게 열어 버튼과 탭을 실제로 눌러 볼 수 있습니다.

홈 오른쪽 위에서 EN, JP, KR을 눌러 언어를 바꿀 수 있고, 여행 취향 태그를 누르면 히어로 문구, 가이드 멘트, 코스 이름, 스탭 순서, 스팟 추천 이유가 함께 바뀝니다. 도보 코스와 로컬 스팟의 카테고리 칩과 영어 메뉴 필터로 목록을 걸러 볼 수 있습니다.

## 구성

- `index.html`, `styles.css`, `app.js`: 빌드 도구 없이 도는 정적 사이트
- `assets/`: 화면에 쓰는 장소 사진 5장(CC0 예시 이미지 3장, 생성 이미지 2장)

화면 속 상점 이름, 평점, 거리, 유동 수치는 기획 검증을 위한 예시 값입니다.
