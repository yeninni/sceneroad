# SceneRoad 씬로드

**K-콘텐츠 속 주인공이 되는 여행.** 씬로드는 좋아하는 드라마 속 장소를 직접 걸어 보는 여행 앱 프로토타입입니다. 가이드 씬로가 촬영지와 주변 맛집, 카페, 찻집을 잇는 산책 코스와 한산한 방문 시간을 추천합니다.

## 이번 개편에서 더한 것

- **타이포그래피**: 영문과 숫자에 Nunito, 한글에 NanumSquareRound, 일본어에 M PLUS Rounded 1c, 브랜드 워드마크에 Fredoka, 픽셀 라벨에 Silkscreen을 조합해 둥글고 귀여운 느낌으로 맞췄습니다.
- **여행 가이드 씬로**는 소개 카드에서 여행 티켓을 들고, 여행 홈에서는 손을 흔듭니다. 혼잡도 화면에서는 수첩을, 주변 가게 화면에서는 돋보기를 듭니다. 도보 코스를 미리 볼 때는 지도 위 경로를 따라 걷습니다.
- **언어와 여행 취향**을 선택하면 씬로의 안내, 도보 코스와 추천 장소가 바뀝니다. 주변 가게에서는 도보 시간과 영어 메뉴 여부를 볼 수 있으며, 영어 메뉴가 있는 곳만 골라 볼 수도 있습니다.

## 화면

| 번호 | 화면 | 내용 |
| --- | --- | --- |
| 01 | 여행 홈 | 촬영지 소개, 여행 취향 고르기, 씬로가 추천하는 코스와 장소 |
| 02 | 방문 시간과 혼잡도 | 시간대별 방문객 수, 한산한 때와 방문 팁 |
| 03 | 도보 코스 | 씬로와 지도에서 코스 미리 보기, 취향별 세 곳, 거리와 도보 시간, 영어 메뉴와 추천 방문 시간 |
| 04 | 주변 가게 | 추천 이유, 도보 시간, 영어 메뉴 여부와 필터 |

## 보는 방법

- **한눈에 보기**에서 네 화면과 서비스 소개를 볼 수 있습니다. 원하는 화면을 누르면 크게 열립니다.
- **모바일로 체험하기**에서 언어, 여행 취향, 코스와 주변 가게를 직접 골라 볼 수 있습니다.

여행 홈 오른쪽 위에서 EN, JP, KR을 눌러 언어를 바꿉니다. 여행 취향을 고른 뒤 도보 코스와 추천 방문 시간이 어떻게 달라지는지 확인해 보세요.

## 구성

- `index.html`, `styles.css`, `app.js`: 빌드 도구 없이 도는 정적 사이트
- `assets/`: 화면에 쓰는 장소 사진 5장(CC0 예시 이미지 3장, 생성 이미지 2장)

화면 속 상점 이름, 평점, 거리, 유동 수치는 기획 검증을 위한 예시 값입니다.
