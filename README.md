# SceneRoad 씬로드

K-콘텐츠 촬영지와 로컬 골목을 잇는 외국인 방문객용 투어 앱 프로토타입입니다. 드라마 촬영지와 그 주변의 맛집, 카페, 전통찻집, 골목 상점을 한 화면에 모아 보여 주고, 방문객에게 취향에 맞춘 도보 코스와 줄 안 서는 방문 시간을 안내합니다.

## 이번 개편에서 더한 것

- **타이포그래피**: 영문과 숫자에 Nunito, 한글에 NanumSquareRound, 일본어에 M PLUS Rounded 1c, 브랜드 워드마크에 Fredoka, 픽셀 라벨에 Silkscreen을 조합해 둥글고 귀여운 느낌으로 맞췄습니다.
- **픽셀 가이드 캐릭터**: 하늘색 베레모를 쓴 픽셀 여행자 `씬로`가 화면마다 다른 모습으로 등장합니다. 홈 히어로는 카메라, 혼잡도 화면은 수첩, 로컬 스팟은 돋보기, 도보 코스 지도는 걷는 자세로 움직입니다.
- **외국인 개인화**: 언어 세 가지(EN, JP, KR)와 여행 취향 다섯 가지를 고르면 가이드 멘트, 추천 촬영지, 도보 코스, 스팟 카드가 함께 바뀝니다. 스팟 카드에는 영어 메뉴 여부, 도보 시간, 추천 이유가 붙고 영어 메뉴만 골라 보는 필터도 있습니다.

## 화면

| 번호 | 화면 | 내용 |
| --- | --- | --- |
| 01 | 방문객 홈 | 촬영지 히어로, 여행 취향 태그, 가이드 멘트, 맞춤 코스 카드, 취향별 추천 스팟 |
| 02 | 방문 시간 & 혼잡도 | 지금 혼잡도와 추천 방문 시간, 시간대별 방문객 흐름과 피크 안내, 픽셀 가이드가 고른 한산한 시간, 방문 팁 세 줄 |
| 03 | 도보 코스 | 미니 동선 지도, 가이드 안내, 카테고리 필터, 취향별 3개 스텝과 도보 시간, 영어 메뉴 표시 |
| 04 | 로컬 스팟 | 다섯 곳 상세 카드, 추천 이유, 도보 시간, 영어 메뉴 여부와 필터 |

## 보는 방법

- **전체 한눈에 보기**: 네 개의 폰 목업과 좌우 요약을 한 화면에 놓은 기획서용 화면입니다. 폰을 누르면 크게 열립니다.
- **모바일로 체험하기**: 폰 한 대를 크게 열어 버튼과 탭을 실제로 눌러 볼 수 있습니다.

홈 오른쪽 위에서 EN, JP, KR을 눌러 언어를 바꿀 수 있고, 여행 취향 태그를 누르면 히어로 문구, 가이드 멘트, 코스 이름, 스탭 순서, 스팟 추천 이유, 추천 방문 시간이 함께 바뀝니다. 도보 코스와 로컬 스팟의 카테고리 칩과 영어 메뉴 필터로 목록을 걸러 볼 수 있습니다.

## 구성

- `index.html`, `styles.css`, `app.js`: 빌드 도구 없이 도는 정적 사이트
- `assets/`: 화면에 쓰는 장소 사진 5장(CC0 예시 이미지 3장, 생성 이미지 2장)

화면 속 상점 이름, 평점, 거리, 유동 수치는 기획 검증을 위한 예시 값입니다.
