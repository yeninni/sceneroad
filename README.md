# SceneRoad 씬로드

K-콘텐츠 촬영지와 로컬 상권을 잇는 투어 앱 프로토타입입니다. 드라마 촬영지와 그 주변의 맛집, 카페, 전통찻집, 골목 상점을 한 화면에 모아 보여 주고, 방문객에게는 도보 코스를, 소상공인에게는 방문 흐름과 운영 팁을 제공합니다.

## 화면

| 번호 | 화면 | 내용 |
| --- | --- | --- |
| 01 | 방문객 홈 | 사내맞선 촬영지 투어, 감고당길 추천 투어, 주변 인기 로컬 스팟, 영문 전환 |
| 02 | 씬로드 파트너 | 보행 점수 88점, 외국인 소비 비중 34.2%, 시간대별 방문 흐름, 오늘의 운영 팁 |
| 03 | 안국 도보 코스 | 미니 동선 지도, 카테고리 필터, 3개 스텝(도보 5분, 7분, 4분), 동선 시작 |
| 04 | 안국 로컬 스팟 | 온미관 안국, 도트블랭킷, 티테라피 행랑점 상세 카드, 카테고리 필터 |

## 보는 방법

- **전체 한눈에 보기**: 네 개의 폰 목업과 좌우 요약을 한 화면에 놓은 기획서용 화면입니다. 폰을 누르면 크게 열립니다.
- **모바일로 체험하기**: 폰 한 대를 크게 열어 버튼과 탭을 실제로 눌러 볼 수 있습니다.

홈 화면의 EN 버튼을 누르면 네 개 화면이 모두 영문으로 바뀝니다. 도보 코스와 로컬 스팟 화면의 카테고리를 누르면 목록이 걸러집니다. 파트너 화면에서는 지역 선택 메뉴가 열립니다.

## 구성

- `index.html`, `styles.css`, `app.js`: 빌드 도구 없이 도는 정적 사이트
- `assets/`: 화면에 쓰는 장소 사진 3장(CC0 예시 이미지)

화면 속 상점 이름, 평점, 거리, 유동 수치는 기획 검증을 위한 예시 값입니다.
